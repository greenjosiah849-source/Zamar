QUICK START
===========

1. Install everything:
   Windows:  install-all.bat
   Linux:    chmod +x install-all.sh && ./install-all.sh

2. Open 4 terminals and run:
   Terminal 1: cd server && npm start
   Terminal 2: cd client && dotnet run  (Zamar Player)
   Terminal 3: cd studio && dotnet run  (Zamar Studio)
   Terminal 4: cd website && npm run dev

3. Access:
   Backend:   http://localhost:3000
   Website:   http://localhost:3001
   Client:    Zamar Player launches as Windows app
   Studio:    Zamar Studio launches as Windows app

TROUBLESHOOTING
===============

Backend won't start:
  - Check port 3000 is available: netstat -ano (Windows) or lsof -i :3000 (Linux)
  - Kill any process on port 3000
  - Check Node.js installed: node --version
  - Reinstall dependencies: cd server && npm install

Client won't launch:
  - Check .NET SDK installed: dotnet --version
  - Restore NuGet packages: dotnet restore
  - Clean build: dotnet clean && dotnet build

Website won't start:
  - Check port 3001 is available
  - Clear npm cache: npm cache clean --force
  - Reinstall: cd website && rm -rf node_modules && npm install

Database connection fails:
  - Check PostgreSQL running
  - Verify connection string in .env
  - Run migrations: npm run migrate

Admin login fails:
  - Verify credentials (zamar/zamar_secure_pass_123)
  - Check JWT_SECRET matches in server
  - Verify admin route exists: GET /api/admin/login
