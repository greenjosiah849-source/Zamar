HOW TO RUN EVERYTHING
======================

INSTALLATION (First Time)
--------------------------
Windows:
  1. Open Command Prompt in /workspaces/Zamar
  2. Run: install-all.bat
  3. Wait for all components to build

Linux/Mac:
  1. Open Terminal in /workspaces/Zamar
  2. Run: chmod +x install-all.sh && ./install-all.sh
  3. Wait for all components to build


STARTUP (After Installation)
-----------------------------
Open 4 separate terminals/windows:

Terminal 1 - Backend Server:
  cd server
  npm start
  Expected: "Server running on http://localhost:3000"

Terminal 2 - Zamar Player Client:
  cd client
  dotnet run
  Expected: Game launcher window opens

Terminal 3 - Zamar Studio Client:
  cd studio
  dotnet run
  Expected: Game editor window opens

Terminal 4 - Website:
  cd website
  npm run dev
  Expected: "ready - started server on 0.0.0.0:3001"
