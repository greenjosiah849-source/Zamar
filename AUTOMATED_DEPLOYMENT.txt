WHAT IF SOMETHING FAILS?
=========================

"command not found: node"
  Solution: Install Node.js from https://nodejs.org/
  Then run script again

"Login failed"
  Solution: Create account at https://expo.dev first
  Then run script again

"Build failed"
  Solution: Usually dependencies issue
  Delete and try again:
    cd mobile
    rm -rf node_modules
    npm install
    eas build --platform all

"Submission failed"
  Solution: Usually no valid builds
  Run deploy script first:
    ./deploy-mobile.sh (Mac/Linux)
    deploy-mobile.bat (Windows)
