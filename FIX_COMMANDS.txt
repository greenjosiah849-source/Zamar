                    ZAMAR - FIX TERMINAL COMMANDS
================================================================================

THE PROBLEM
===========

Commands weren't working because:
  1. Expo CLI wasn't installed globally
  2. EAS CLI wasn't installed globally  
  3. npm scripts called non-existent commands
  4. Missing Node.js/npm dependencies


THE SOLUTION
============

Run these commands ONE AT A TIME in terminal:


STEP 1: Install Global Tools
============================

Windows PowerShell (as Administrator):
  npm install -g expo-cli@latest
  npm install -g eas-cli@latest

Linux/Mac (Terminal):
  sudo npm install -g expo-cli@latest
  sudo npm install -g eas-cli@latest


STEP 2: Install Mobile App Dependencies
========================================

cd mobile
npm install
npm install --save-dev @react-navigation/native @react-navigation/bottom-tabs


STEP 3: Install Server Dependencies
====================================

cd ../server
npm install


STEP 4: Install Website Dependencies
=====================================

cd ../website
npm install


STEP 5: Verify Everything Works
===============================

Check tools are installed:
  expo --version
  eas --version
  node --version
  npm --version

Should show version numbers like "expo@48.0.0"


NOW YOU CAN USE THESE COMMANDS
==============================

Mobile App:
  cd mobile
  expo start                    ← Start dev server
  expo start --android         ← Start Android emulator
  expo start --ios             ← Start iOS emulator
  eas build --platform android ← Build for Google Play
  eas build --platform ios     ← Build for App Store
  eas build --platform all     ← Build both

Server:
  cd server
  npm start                     ← Start backend

Website:
  cd website
  npm run dev                   ← Start website dev

WHAT EACH COMMAND DOES
=======================

npm install -g expo-cli
  → Installs Expo CLI globally (worldwide)
  → Lets you use "expo" command anywhere
  → One-time install

npm install -g eas-cli
  → Installs EAS CLI globally (worldwide)
  → Lets you use "eas" command anywhere
  → One-time install

cd mobile
  → Goes to mobile folder
  → Must do this before running mobile commands

npm install
  → Installs node_modules folder
  → Downloads all dependencies
  → Takes 2-5 minutes first time

expo start
  → Starts development server
  → Shows QR code in terminal
  → Scan with Expo Go on phone
  → Press 'a' for Android, 'i' for iOS

eas build --platform all
  → Builds app for iOS and Android
  → Creates app installers
  → Takes 10-30 minutes
  → Requires Expo account


TROUBLESHOOTING
===============

"command not found: npm"
  Problem: Node.js not installed
  Solution: Install from https://nodejs.org/
  Then: Close terminal and open new one
  Then: npm --version

"command not found: expo"
  Problem: Expo CLI not installed
  Solution: npm install -g expo-cli@latest
  Then: Close terminal and open new one
  Then: expo --version

"command not found: eas"
  Problem: EAS CLI not installed
  Solution: npm install -g eas-cli@latest
  Then: Close terminal and open new one
  Then: eas --version

npm install fails
  Solution 1: cd mobile && rm -rf node_modules && npm install
  Solution 2: npm cache clean --force
  Solution 3: Update npm: npm install -g npm@latest

expo start not working
  Solution 1: cd mobile && npm install
  Solution 2: expo login (create account at expo.dev)
  Solution 3: expo start --clear

Can't scan QR code
  Problem: Phone not on same WiFi as computer
  Solution 1: Connect to same WiFi network
  Solution 2: Use USB cable: expo start --tunnel
