HOW TO USE
==========

1. INSTALLATION:
   - Run install-all.bat (Windows) or install-all.sh (Linux/Mac)
   - Or run setup.bat/setup.sh for manual setup

2. RUNNING COMPONENTS:
   Terminal 1: cd server && npm start
   Terminal 2: cd client && dotnet run
   Terminal 3: cd website && npm run dev
   Terminal 4: cd studio && dotnet run

3. LAUNCHING ZAMAR PLAYER:
   - Client runs with launcher window
   - Theme selector in settings
   - Browse and launch games
   - Create multiplayer sessions or join existing ones
   - Play games with real-time player synchronization

4. CREATING GAMES:
   - Open Zamar Studio (terminal 4)
   - Create new game project
   - Add parts and scripts
   - Test and publish
   - Players can discover your game in the launcher

5. GAME MECHANICS:
   - WASD/Arrow keys to move
   - Space to jump
   - Mouse to aim/rotate
   - Click to attack
   - Real-time multiplayer synchronization
   - Health and combat system
   - Character animations

6. MULTIPLAYER:
   - Sessions: Create or join game sessions
   - Matchmaking: Use auto-match to find games
   - Combat: Attack other players in real-time
   - Sync: Positions update at 60Hz
   - Stats: Track kills, deaths, wins
