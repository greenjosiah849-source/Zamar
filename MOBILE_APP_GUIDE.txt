SETUP & TESTING
===============

1. Install Dependencies:
   cd mobile
   npm install

2. Start Development Server:
   expo start

3. Test on Phone (Easiest):
   - Download Expo Go app (App Store or Google Play)
   - Scan QR code from terminal
   - App loads on your phone

4. Test in Emulator:
   Press 'a' for Android emulator
   Press 'i' for iOS emulator (Mac only)


BUILD FOR DISTRIBUTION
======================

OPTION 1: Using EAS (Easiest - Recommended)
-------------------------------------------

1. Create Expo Account:
   expo login

2. Create EAS project:
   eas build:configure

3. Build for Android:
   eas build --platform android --auto-submit

4. Build for iOS:
   eas build --platform ios --auto-submit

5. Build Both:
   eas build --platform all --auto-submit

OPTION 2: Manual Build (Advanced)
----------------------------------

Android (Manual):
   eas build --platform android
   (Creates APK file)
   Use Android Studio to sign and submit to Play Store

iOS (Manual):
   eas build --platform ios
   (Creates IPA file)
   Use Xcode to sign and submit to App Store


SUBMIT TO APP STORES
====================

GOOGLE PLAY STORE
-----------------

1. Create Google Play Developer Account:
   - Go to play.google.com/apps/publish
   - Pay $25 one-time fee
   - Fill app details

2. Build APK:
   eas build --platform android

3. Create New App in Play Store:
   - App name: "Zamar"
   - Category: Games
   - Content rating questionnaire

4. Upload APK:
   - Go to "Releases" > "Production"
   - Upload APK file
   - Fill version, notes, screenshots

5. Review & Publish:
   - Google reviews in 24-48 hours
   - Once approved, app goes live

APP STORE (iOS)
---------------

1. Create Apple Developer Account:
   - Go to developer.apple.com
   - Enroll in Apple Developer Program ($99/year)
   - Create App ID: "Zamar"

2. Build IPA:
   eas build --platform ios

3. Create App in App Store Connect:
   - App name: "Zamar"
   - Bundle ID: com.zamarplatform.zamar
   - Category: Games

4. Upload Build:
   - Use Xcode or Transporter
   - Upload IPA file
   - Fill version, notes, screenshots

5. Submit for Review:
   - Fill content rating
   - Add privacy policy
   - Submit for review

6. Apple Reviews in 1-5 days:
   - Once approved, app goes live
