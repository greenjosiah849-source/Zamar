WHAT CHANGED
============

eas.json now only contains BUILD configuration (no submit).

Why? The submit section needed special credentials that most developers don't 
have. Instead, you'll submit your builds manually through:
  - Google Play Console (Android)
  - App Store Connect (iOS)

This is actually simpler and gives you more control!

HOW TO GET YOUR BUILD FILES
============================

After "eas build --platform all" completes:

1. Get your build link:
   eas build:list
   (Shows all your builds with download links)

2. Or download directly:
   eas build:download --id <build-id>
   (ID shown when build finishes)

3. Files you get:
   - APK file (for Google Play) - about 50-80 MB
   - IPA file (for App Store) - about 60-100 MB

1. Login to Expo:

SUBMITTING TO GOOGLE PLAY
==========================

Prerequisites:
  ✓ Google account
  ✓ $25 one-time fee
  ✓ APK build file
  ✓ App info ready

Steps:

1. Create account:
   https://play.google.com/apps/publish
   Pay $25 fee
   Verify identity

2. Create new app:
   Name: "Zamar"
   Category: Games
   Content rating: Take questionnaire

3. Fill app information:
   Short description (80 chars): "Multiplayer game platform"
   Full description (4000 chars): Full details
   Screenshots: 2-5 phone screenshots
   Featured image: 1024x500 PNG
   Icon: 512x512 PNG

4. Set up content rating:
   Answer questions about content
   Get IARC rating

5. Upload APK:
   Go to "Release" tab
   Click "Production"
   Upload APK file
   Version code: 1
   Release notes: "Initial launch"

6. Set pricing:
   Free (selected by default)

7. Submit for review:
   Click "Submit"
   Google reviews in 24-48 hours


SUBMITTING TO APP STORE
=======================

Prerequisites:
  ✓ Apple ID
  ✓ $99/year fee
  ✓ IPA build file
  ✓ App info ready

Steps:

1. Create account:
   https://developer.apple.com
   Enroll in Developer Program
   Pay $99/year
   Accept agreements

2. Go to App Store Connect:
   https://appstoreconnect.apple.com

3. Create new app:
   "My Apps" → "+"
   Name: "Zamar"
   Bundle ID: com.zamarplatform.zamar
   Platform: iOS
   SKU: zamar-001 (any unique ID)

4. Fill app information:
   Subtitle: "Multiplayer Gaming"
   Privacy policy: Add URL
   Guidance: Select rating (4+, 12+, 17+)
   Screenshots: iPhone + iPad required
   App preview: Optional video

5. Prepare for submission:
   App information ✓
   Pricing and Availability ✓
   App privacy ✓

6. Build & upload:
   Use Transporter (Apple tool)
   Upload IPA file
   Version: 1.0.0
   Build number: 1

7. Complete information:
   Version release notes: "Launch version"
   Phased release: Optional

8. Submit for review:
   Click "Submit for Review"
   Apple reviews in 1-5 days

TROUBLESHOOTING BUILDS
======================

Build never finishes:
  Wait 30 minutes minimum
  Normal for first build
  Check: eas build:list
  If stuck 1+ hour: Ctrl+C and retry

Can't download build:
  1. Get build ID: eas build:list
  2. Download: eas build:download --id [id]
  3. Or visit link from eas build:list

Wrong file type:
  Android: Should be .apk or .aab file
  iOS: Should be .ipa file
  If wrong: Rebuild

Submission rejected:
  1. Read rejection reason carefully
  2. Fix the issue
  3. Resubmit same version
  4. Or create new build


COMMON REJECTION REASONS
========================

Google Play:
  - App crashes on launch
  - Incomplete app store listing
  - No privacy policy
  - Adults only content not rated
  - Broken permissions

App Store:
  - App crashes on launch
  - Incomplete app information
  - No privacy policy
  - Doesn't match description
  - Bugs or incomplete features


HOW TO FIX ISSUES
=================

If your app is rejected:

1. Read the rejection email
2. Understand what's wrong
3. Fix in code (if needed)
4. Or fix in app store listing
5. Resubmit

For code issues:
  1. Fix code
  2. Build new version: eas build --platform all
  3. Download new APK/IPA
  4. Upload to store
  5. Resubmit

For listing issues:
  1. Update descriptions
  2. Add screenshots
  3. Fix privacy policy
  4. Resubmit (no new build needed)
