     * Calculates best server based on location
     * Provides initial game state
   - Metrics endpoint: /api/multiplayer/metrics

   - WebSocket real-time communication

--- INTEGRATION POINTS ---

CLIENT -> SERVER:
- REST API calls via RestSharp
  * GET /api/games/featured
  * GET /api/games/search?q=
  * GET /users/me
  * POST /api/multiplayer/join
  * GET /api/multiplayer/metrics

- WebSocket connections
  * Real-time player state sync
  * Game input transmission
  * Chat messaging
  * Server broadcast events

SERVER -> CLIENT:
- JSON REST responses
  * Game metadata
  * Server metrics
  * Join tokens
  * Leaderboards

- WebSocket messages
  * player_update (position, animation)
  * player_action (attacks, effects)
  * chat_message (in-game chat)
  * game_state (world updates)
  * player_joined / player_left
  * heartbeat (keep-alive)
