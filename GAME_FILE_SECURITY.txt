CREATING GAME FILES
===================

C# - Using GameFileSerializer:

  // Initialize serializer with master key and developer key
  var masterKey = Encoding.UTF8.GetBytes("your-master-key-32-bytes-min");
  var developerKey = "your-developer-key";
  var serializer = new GameFileSerializer(masterKey, developerKey);

  // Create and save game place
  var gamePlace = new GamePlace
  {
      Name = "My Awesome Game",
      Description = "A fun game for everyone"
  };
  serializer.SaveZmblxFile("MyGame.zmblx", gamePlace);

  // Create and save game model
  var model = new GameModel
  {
      Name = "Player Model"
  };
  serializer.SaveZmFile("PlayerModel.zm", model);


LOADING GAME FILES
==================

C# - Using GameFileValidator and GameFileSerializer:

  // Validate file first
  var validator = new GameFileValidator();
  var validationResult = validator.ValidateZmblxFile("MyGame.zmblx");

  if (validationResult.IsValid)
  {
      // Load file if valid
      var serializer = new GameFileSerializer(masterKey, developerKey);
      var gamePlace = serializer.LoadZmblxFile("MyGame.zmblx");
      // Use gamePlace...
  }
  else
  {
      // Handle validation errors
      foreach (var error in validationResult.Errors)
      {
          Console.WriteLine($"Error: {error.Message}");
      }
  }

SERVER ANTI-CHEAT SYSTEM
========================

Prevents:
  ✓ Speed hacking (moving too fast)
  ✓ Position hacking (teleportation)
  ✓ Jump hacking (jumping too high)
  ✓ Action spam (too many commands)
  ✓ Script injection (malicious code)
  ✓ Collision bypass (walking through walls)

Usage:

  // Initialize anti-cheat for game session
  var antiCheat = new AntiCheatService();
  antiCheat.RegisterPlayerSession("player123", "session456", "game789");

  // Validate each player action
  var action = new PlayerAction
  {
      Position = (100.0, 50.0, 200.0),
      ActionType = "move",
      JumpHeight = 5.0
  };

  if (!antiCheat.ValidatePlayerAction("session456", action))
  {
      Console.WriteLine("Cheat detected! Action rejected");
  }

  // Analyze session for patterns
  var analysis = antiCheat.AnalyzeSession("session456");
  if (analysis.CheatProbability > 0.7)
  {
      Console.WriteLine("Player is likely cheating!");
      foreach (var cheat in analysis.DetectedCheats)
      {
          Console.WriteLine($"  - {cheat}");
      }
  }

  // End session and get final report
  var finalResult = antiCheat.EndSession("session456");

FILE STRUCTURE
==============

ZMBLX Header (64 bytes):
  Magic: "ZMBLX" (5 bytes)
  Version: 1.0 (2 bytes)
  Flags: 0x01 (encrypted) (1 byte)
  Reserved: (56 bytes)

Metadata (Variable):
  Game Name, Author, Version
  Created/Modified timestamps
  Game ID (UUID)
  Digital Signature (HMAC-SHA256)

Content (Encrypted):
  Parts List
  Scripts List
  Objects List
  Settings
  Assets

Footer:
  CRC32 Checksum (4 bytes)

ZM Header (32 bytes):
  Magic: "ZM" (2 bytes)
  Version: 1.0 (2 bytes)
  Flags: (1 byte)
  Reserved: (27 bytes)

Model Data (Encrypted):
  Parts (mesh, collision)
  Animations
  Properties
  Scripts

Footer:
  CRC32 Checksum (4 bytes)

TROUBLESHOOTING
===============

Validation failed: "Invalid header"
  → File is not valid .zmblx or .zm
  → Check file wasn't corrupted
  → Regenerate file

"File signature verification failed"
  → File was modified after creation
  → Wrong encryption key
  → Regenerate file

"Malware detected - File quarantined"
  → File contains suspicious patterns
  → Check file source
  → Manual review in quarantine folder

"Cannot decrypt file"
  → Wrong decryption key
  → File is corrupted
  → Try backup copy

Cheat detection false positives
  → Adjust speed/position thresholds
  → Account for lag/latency
  → Test with legitimate players
