FIRST TIME SETUP (RUN THIS FIRST!)
==================================

Windows:
  Double-click: DEPLOYMENT_SETUP.bat
  
Linux/Mac:
  chmod +x DEPLOYMENT_SETUP.sh
  ./DEPLOYMENT_SETUP.sh


TESTING MOBILE APP
==================

1. Go to mobile folder:
   cd mobile

2. Start development:
   expo start

3. On your phone:
   - Download Expo Go app (free)
   - App Store or Google Play
   - Scan QR code from terminal
   - App loads on phone

4. Test all screens:
   - Home: Featured games
   - Games: Game list
   - Servers: Server browser
   - Profile: User stats
   - Settings: Preferences


BUILDING FOR STORES
===================

After testing locally, build for app stores:

Build Android (Google Play):
  cd mobile
  eas build --platform android

Build iOS (App Store):
  cd mobile
  eas build --platform ios

Build BOTH:
  cd mobile
  eas build --platform all


SUBMITTING TO STORES
====================

After build completes, submit:

Submit Android (Google Play):
  cd mobile
  eas submit --platform android

Submit iOS (App Store):
  cd mobile
  eas submit --platform ios

Submit BOTH:
  cd mobile
  eas submit --platform all


STARTING SERVERS
================

Backend Server:
  cd server
  npm start
  (Runs on http://localhost:3000)

Website:
  cd website
  npm run dev
  (Runs on http://localhost:3001)

Game Server (Windows):
  cd client
  dotnet run
  (Starts simplified launcher)

=====================

  → npm install -g expo-cli

"eas: command not found"
  → npm install -g eas-cli

"npm: command not found"
  → Install Node.js from nodejs.org

Dependencies errors in mobile:
  → cd mobile
  → rm -rf node_modules
  → npm install

Dependencies errors in server:
  → cd server
  → rm -rf node_modules
  → npm install

Dependencies errors in website:
  → cd website
  → rm -rf node_modules
  → npm install

TROUBLESHOOTING
===============

1. Can't find commands?
   → Make sure you ran DEPLOYMENT_SETUP first
   → Restart terminal after setup

2. Mobile app won't load?
   → Check backend server is running (cd server && npm start)
   → Make sure phone is on same network
   → Try "expo start" again

3. Expo won't start?
   → Delete node_modules and reinstall:
     cd mobile
     rm -rf node_modules
     npm install
     expo start

4. EAS won't build?
   → Make sure you're logged in: expo login
   → Check you have Expo account at https://expo.dev
   → Try: eas build --platform android --auto-submit

5. Stuck on build?
   → Check build status: eas build:list
   → View logs: eas build:view --id <build-id>
