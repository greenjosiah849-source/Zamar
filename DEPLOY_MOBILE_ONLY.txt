STEP 4: BUILD FOR APP STORES
============================

Build for Android (Google Play):

Build for iOS (App Store):

Build for BOTH (Recommended):

Will take 10-30 minutes. EAS will show progress in terminal.

===================================

You'll see:

  → Build in progress...
  ✓ Build completed!

The build is stored on EAS servers, NOT your computer.


STEP 6: SUBMIT TO APP STORES
============================

IMPORTANT: You need developer accounts for this

Android (Google Play):
  1. Create account at: https://play.google.com/apps/publish
  2. Pay $25 one-time fee
  3. Run: eas submit --platform android
  4. EAS will guide you through submission

iOS (App Store):
  1. Create account at: https://developer.apple.com
  2. Pay $99/year fee
  3. Run: eas submit --platform ios
  4. EAS will guide you through submission

Without accounts:
  eas build --platform all    ← Just builds
  (Don't run eas submit)
  (Can test locally with Expo Go first)

TROUBLESHOOTING
===============

"expo login" fails
  Error: "Your username, email, or password was incorrect"
  
  Solution:
    1. Go to https://expo.dev
    2. Click "Forgot password"
    3. Reset password
    4. Try login again: expo login
    5. Verify email if needed

"eas build" fails
  Error: "eas.json not found"
  
  Solution:
    ✓ Already fixed! eas.json is created in /mobile
    Make sure you're in /mobile folder:
      cd /workspaces/Zamar/mobile

"Can't find mobile folder"
  Error: "bash: cd: mobile: No such file or directory"
  
  Solution:
    Go to Zamar folder first:
      cd /workspaces/Zamar
    Then go to mobile:
      cd mobile
    Confirm you're there:
      pwd
      (should show: /workspaces/Zamar/mobile)

"Build takes too long"
  Normal: 10-30 minutes
  Very normal to seem stuck for 10+ minutes
  DON'T close terminal, let it finish
  
  If still stuck after 1 hour:
    Ctrl+C to stop
    Try again: eas build --platform all

"Submission fails"
  Error: Usually means missing developer account
  
  Solution:
    - Google Play: Create account at play.google.com/apps/publish
    - App Store: Create account at developer.apple.com
    - Pay fees
    - Follow eas submit prompts
