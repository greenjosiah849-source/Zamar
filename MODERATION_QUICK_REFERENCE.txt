## Service Initialization Template

```javascript
// 1. Import all services
const BatchModerationService = require('./services/batch-moderation');
const CustomRuleBuilderService = require('./services/custom-rule-builder');
const MobileAPIService = require('./services/mobile-api');
const NotificationService = require('./services/notification-service');
const AnalyticsService = require('./services/analytics-service');
const MLTrainerService = require('./services/ml-trainer');

// 2. Create instances
const services = {
  batchService: new BatchModerationService(pool, redis, modService),
  ruleService: new CustomRuleBuilderService(pool, redis),
  mobileService: new MobileAPIService(pool, redis, modService),
  notificationService: new NotificationService(pool, redis, emailConfig),
  analyticsService: new AnalyticsService(pool, redis),
  mlTrainer: new MLTrainerService(pool, redis)
};

// 3. Register routes
app.use('/api/moderation', require('./routes/moderation-complete')(
  pool, redis, modService, services
));

// 4. Start WebSocket server
const ModerationWebSocketServer = require('./services/moderation-websocket');
new ModerationWebSocketServer(httpServer, modService).setupWebSocketServer();
```

## WebSocket Client Example

```javascript
const ws = new WebSocket('ws://localhost:3001');

ws.onopen = () => {
  // Subscribe to moderation cases
  ws.send(JSON.stringify({
    action: 'subscribe',
    topic: 'MODERATION_CASES',
    token: jwtToken
  }));
};

ws.onmessage = (event) => {
  const { type, data } = JSON.parse(event.data);
  if (type === 'CASE_CREATED') {
    console.log('New case:', data);
  }
};
```

## API Endpoints Cheat Sheet

**Cases**
- `POST /api/moderation/scan` - Scan content
- `POST /api/moderation/report` - Report content
- `GET /api/moderation/cases` - Get all cases
- `POST /api/moderation/cases/:id/review` - Review case

**Batch**
- `POST /api/moderation/batch/approve-cases` - Batch approve
- `POST /api/moderation/batch/ban-users` - Batch ban
- `GET /api/moderation/batch/jobs` - Get batch jobs

**Rules**
- `POST /api/moderation/rules` - Create rule
- `GET /api/moderation/rules` - Get all rules
- `POST /api/moderation/rules/test` - Test rule

**Mobile**
- `POST /api/moderation/mobile/report` - Mobile report
- `GET /api/moderation/mobile/violations/:id` - Get violations
- `GET /api/moderation/mobile/ban-status/:id` - Check ban

**Analytics**
- `GET /api/moderation/analytics/overview?timeRange=7d` - Dashboard
- `GET /api/moderation/analytics/violations?timeRange=30d` - Violation stats
- `GET /api/moderation/analytics/report?timeRange=30d` - Full report

**ML**
- `POST /api/moderation/ml/train` - Train model
- `GET /api/moderation/ml/stats` - Training stats
- `GET /api/moderation/ml/versions` - Model versions
- `POST /api/moderation/ml/versions/:id/rollback` - Rollback model

**Notifications**
- `GET /api/moderation/notifications/:userId` - Get notifications
- `PUT /api/moderation/notifications/:id/read` - Mark as read

## Performance Tips

1. **Cache frequently accessed rules**: Set to Redis with 3600s TTL
2. **Batch operations**: Process 50-100 items per batch for optimal speed
3. **Async notifications**: Don't wait for email sends
4. **ML training**: Run off-peak during low traffic (2-3 AM)
5. **WebSocket**: Use topic subscriptions to reduce broadcast size
6. **Analytics**: Cache reports for 30min during business hours
7. **Database**: Use LIMIT/OFFSET for pagination
8. **Indexes**: Ensure indexes on `user_id`, `created_at`, `status`

## Troubleshooting

| Problem | Solution |
|---------|----------|
| WebSocket won't connect | Check JWT token validity, verify WS_URL |
| Batch operations timeout | Reduce batch size to 50 items, check DB pool |
| Notifications not sending | Verify SMTP credentials, check email provider |
| ML training fails | Ensure 100+ training samples, check disk space |
| Rules not matching | Test rule with `/rules/test` endpoint |
| Analytics slow | Add indexes, cache results, check query |
| Out of memory | Enable Redis connection pooling |
