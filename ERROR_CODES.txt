================================================================================
                        ZAMAR ERROR CODES SYSTEM
================================================================================

COMPLETE ERROR CODE REFERENCE FOR ALL SYSTEMS
==============================================

Error codes follow format: [SYSTEM]_[CATEGORY]_[SEVERITY]_[CODE]
Example: SRV_AUTH_ERR_001 = Server Authentication Error #001


================================================================================
                          AUTHENTICATION ERRORS
================================================================================

Format: AUTH_XXX

AUTH_001: Invalid credentials
  Status: 401 Unauthorized
  Message: "Email or password is incorrect"
  Recovery: Prompt user to try again or reset password

AUTH_002: Account not found
  Status: 404 Not Found
  Message: "No account found with that email"
  Recovery: Suggest account creation or email recovery

AUTH_003: Account suspended
  Status: 403 Forbidden
  Message: "Your account has been suspended"
  Recovery: Contact support for reinstatement

AUTH_004: Account locked (too many login attempts)
  Status: 429 Too Many Requests
  Message: "Account locked due to too many failed attempts"
  Recovery: Wait 30 minutes or verify email for instant unlock

AUTH_005: Session expired
  Status: 401 Unauthorized
  Message: "Your session has expired. Please log in again."
  Recovery: Redirect to login page, preserve user data

AUTH_006: Invalid token
  Status: 401 Unauthorized
  Message: "Invalid authentication token"
  Recovery: Force re-login

AUTH_007: Token expired
  Status: 401 Unauthorized
  Message: "Your token has expired. Please log in again."
  Recovery: Refresh token or re-login

AUTH_008: Two-factor authentication required
  Status: 403 Forbidden
  Message: "Two-factor authentication code required"
  Recovery: Prompt for 2FA code

AUTH_009: Invalid 2FA code
  Status: 401 Unauthorized
  Message: "Invalid two-factor code"
  Recovery: Prompt for correct code

AUTH_010: Email not verified
  Status: 403 Forbidden
  Message: "Please verify your email address"
  Recovery: Send verification email

================================================================================
                          ERROR CODE CATEGORIES
================================================================================

1xx - Informational (processing continues)
2xx - Success (operation completed)
3xx - Redirection (further action needed)
4xx - Client Error (invalid request)
5xx - Server Error (server failure)

By Category:
  001-010: Authentication
  011-020: Authorization
  021-030: Validation
  031-040: Database
  041-050: File Operations
  051-060: Network
  061-070: Game Logic
  071-080: Server
  081-090: Client
  091-100: System


================================================================================
                          ERROR HANDLING FLOW
================================================================================

1. Error occurs
2. Error caught by handler
3. Error code assigned
4. Error logged with context
5. Error type determined
6. Recovery strategy applied
7. User notified (if needed)
8. Error telemetry sent
9. Admin alert (if critical)
10. Detailed logs saved
