ZAMAR COMPLETE INSTALLATION & QUICK START GUIDE
================================================

INSTALLATION INSTRUCTIONS
=========================

## Windows Users:
1. Open Command Prompt or PowerShell in the Zamar root directory
2. Run: install-all.bat
3. Wait for all components to install and build

## Linux/Mac Users:
1. Open Terminal in the Zamar root directory
2. Run: chmod +x install-all.sh && ./install-all.sh
3. Wait for all components to install and build

## Manual Installation (if scripts don't work):

### Backend Server:
cd server
npm install
npm start

### Zamar Player Client:
cd client
dotnet restore
dotnet build -c Release
dotnet run

### Zamar Studio:
cd studio
dotnet restore
dotnet build -c Release
dotnet run

### Website:
cd website
npm install
npm run dev


RUNNING INDIVIDUAL COMPONENTS
=============================

### Start Backend Server:
cd server && npm start
Server runs on: http://localhost:3000

### Start Zamar Player:
cd client && dotnet run
Launches the main game launcher client

### Start Zamar Studio:
cd studio && dotnet run
Opens the game development editor

### Start Website:
cd website && npm run dev
Website runs on: http://localhost:3000

TROUBLESHOOTING
===============

If npm install fails:
- Clear npm cache: npm cache clean --force
- Delete node_modules: rm -rf node_modules
- Re-run npm install

If dotnet build fails:
- Clear build: dotnet clean
- Restore: dotnet restore
- Build again: dotnet build

If server won't start:
- Check if port 3000 is available
- Try: netstat -ano (Windows) or lsof -i :3000 (Linux/Mac)
- Kill process using port 3000 if needed

FIRST TIME SETUP
================

1. Install all components using install-all.bat or install-all.sh
2. Start the backend server first: cd server && npm start
3. In another terminal, start the client: cd client && dotnet run
4. The launcher window will open
5. Create a test account or login
6. Start a game or open Zamar Studio to create one

DEVELOPMENT
===========

To modify code:
- Client code: /client (C# WPF)
- Server code: /server/src (Node.js Express)
- Website code: /website (Next.js React)
- Studio code: /studio (C# WPF)

To rebuild after changes:
- Client: cd client && dotnet build
- Server: npm start (reloads automatically)
- Website: npm run dev (reloads automatically)

Combat:
POST   /api/multiplayer/attack

Sessions:
POST   /api/multiplayer/session/create
POST   /api/multiplayer/session/join
GET    /api/multiplayer/sessions/:gameId

Matchmaking:
POST   /api/multiplayer/matchmake

Stats:
